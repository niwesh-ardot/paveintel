# PaveIntel Agent Instructions

PaveIntel is an AI research intelligence platform for concrete pavement researchers and DOT engineers.

Do not treat this as a generic PDF chatbot. The product must focus on structured engineering knowledge extraction, citation-backed research answers, document comparison, and literature-review workflows.

Always prioritize:
- Clean TypeScript
- Modular components
- Clear data models
- Pavement-engineering-specific mock data
- Traceable evidence and citation UI
- Human review workflow
- Serious professional SaaS design

Core domain concepts:
- CRCP
- JPCP
- Whitetopping
- Bonded and unbonded concrete overlays
- FWD
- LTE
- k-value
- Deflection basin
- Backcalculation
- AASHTO 1993
- MEPDG
- TxDOT
- FHWA
- NCHRP
- Overlay thickness design
- Modulus of rupture
- Fatigue cracking
- Punchouts
- Faulting
- Curling and warping

The current app may use mock data, but structure the code so real PDF parsing, OpenAI extraction, embeddings, vector search, and database storage can be added later.
